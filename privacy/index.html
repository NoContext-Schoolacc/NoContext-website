PRIVACY POLICY

Your data.
Your control.

How NoContext handles information used for accounts, licenses, support, security, and site operation.

Last updated

September 11, 2026

1. What this policy covers

This Privacy Policy explains what information the NoContext website and its backend services collect, why that information is processed, and the choices available to you. It is written to match the data fields and processing currently implemented by the NoContext website.

2. Information you provide

  • Account information: your chosen username and, when you create a password-based account, a securely derived password hash and salt. No plain-text password is stored by the application.
  • Discord account information: if you use Discord sign-in, the service receives and stores your Discord user ID, Discord username/display name, and avatar identifier returned by Discord.
  • Support information: if you open a support ticket, we store the ticket category, priority, subject, description, status, timestamps, and messages you send. Staff replies are also stored so the conversation can be maintained.
  • License information: license records can include a securely hashed license key, product identifier, license status, expiration time, claim/validation timestamps, and securely hashed verification-token information used by the license system.

3. Information collected automatically

The backend records limited operational information for security, abuse prevention, and troubleshooting. This currently includes:

  • a keyed cryptographic hash of the IP address associated with certain license-claim attempts;
  • a keyed cryptographic hash of the IP address associated with client-error reports;
  • short client error information, including an event type, a truncated error message, and the page path where the error occurred; and
  • technical session information needed to keep an authenticated account signed in.

The client monitoring code is designed to send only the short error information described above. It does not intentionally collect passwords, license keys, or the contents of support tickets through the error-monitoring endpoint.

4. Cookies and sessions

NoContext uses an HTTP-only session cookie to maintain signed-in sessions. In production, the session cookie is marked Secure and uses SameSite=Lax. Session records expire after seven days, and a new login replaces prior sessions for that account.

Discord sign-in also uses a short-lived security-state cookie. The state is stored server-side as a keyed hash and expires after approximately ten minutes. These cookies are functional authentication/security cookies, not advertising cookies.

5. How information is used

Information is used to provide and secure the service, including to create and authenticate accounts, connect optional Discord sign-in, issue and validate licenses, provide support tickets, prevent abuse, enforce rate limits, troubleshoot client errors, maintain service security, and operate the website.

6. Third-party services

NoContext can interact with third-party services when a feature requires them:

  • Discord: optional Discord authentication sends the OAuth authorization request to Discord and uses the Discord API to obtain the profile information described above. Discord's own privacy practices apply to information processed by Discord.
  • Work.ink: the license-claim flow can use Work.ink verification links/tokens. Information handled by Work.ink is subject to Work.ink's own policies.
  • Payment providers: the website contains a checkout integration point intended for a payment provider. The current backend can return a checkout-unavailable response until payment configuration is enabled. If payments are enabled, payment information should be processed by the configured provider under that provider's terms and privacy policy rather than stored as raw card data by the NoContext frontend.

7. What we do not intentionally store

The current application is designed so that account passwords are not stored in plain text, license keys are stored as cryptographic hashes where they are persisted, and session tokens are stored as cryptographic hashes rather than raw session tokens. Do not submit passwords, API keys, session tokens, or other credentials in support tickets.

8. Data retention

Information is retained for as long as it is needed for the purposes described in this policy, including account operation, license administration, support history, security, and troubleshooting. The application automatically expires seven-day login sessions and ten-minute Discord OAuth states. Other records, such as accounts, tickets, licenses, and security logs, do not currently have an automatic deletion period in the application code.

9. Security

NoContext uses measures including HTTPS requirements for production Discord callbacks, HTTP-only/Secure/SameSite cookies, cryptographic hashing for sensitive stored tokens, password hashing with scrypt, rate limiting, same-origin checks on state-changing requests, parameterized database queries, and security-related HTTP headers. No online service can guarantee absolute security.

10. Your choices and privacy requests

You may stop using the service and may request information about or deletion of personal information associated with your account where applicable. Because the current site does not provide a self-service account deletion control, privacy requests can be submitted through the Contact page. We may need to verify that a request relates to the account concerned before acting on it.

11. Changes to this policy

This policy may be updated when the website's features, data processing, or legal requirements change. The “Last updated” date at the top of this page will be changed when material revisions are made. Continued use of the service after an update means the revised policy applies to future use.

12. Contact

For privacy questions or requests, use the NoContext support page. Please do not include passwords, API keys, session tokens, or other secret credentials in a privacy request or support ticket.
